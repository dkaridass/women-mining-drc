# Images Directory

## Hero Image
- `hero.webp` - Hero background (1920x1080px recommended, WebP format)

## Gallery Images
Place 6-12 gallery images in `gallery/` folder:
- `gallery/1.webp` through `gallery/12.webp`
- Recommended: 1200x800px, WebP format for optimal performance

## Current Setup
The site uses images from `/attached_assets/` as fallback.
For production, convert all images to WebP format for <2s load time.

## Image Optimization Tips
- Use WebP format (90% smaller than JPEG)
- Compress images before upload
- Use appropriate sizes:
  - Hero: 1920x1080px
  - Gallery: 1200x800px
  - Thumbnails: 400x300px
